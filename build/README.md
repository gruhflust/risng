# Build assets

This directory keeps non-deployed development assets separate from the
Ansible delivery tree.

- `config/` contains local build configuration placeholders.
- `container/` contains container build inputs.
- `functions/admin/` contains operator diagnostics and administration helpers.
- `legacy/` contains retained historical playbooks.
- `logs/` contains checked-in sample runtime output.
- `runtime/` contains local runtime placeholders.
- `tools/python/` contains development and NetBox helper scripts.
- `requirements.yml` lists build-time Ansible collections.
